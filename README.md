# Snippetbox

[Открыть приложение](https://snippetbox-aartchik.duckdns.org/)

Snippetbox - это браузерное веб-приложение для коротких текстовых заметок и сниппетов. В нем можно зарегистрироваться, войти в аккаунт, создать заметку с заголовком и текстом, посмотреть последние записи, найти нужную заметку через поиск и открыть отдельную заметку по ссылке.
