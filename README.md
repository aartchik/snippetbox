# Snippetbox

[Ссылка](https://snippetbox-aartchik.duckdns.org/)

Snippetbox - это браузерное веб-приложение с авторизацией для коротких текстовых заметок и сниппетов. Настроенно CI/CD, развертывание на Yandex Cloud. Собрано через docker compose с зависимостями базы данных, redis, миграциями, unit, e2e тестами.
